## 🎨 主要改进

### 1. 彩色卡片式消息框
所有消息现在显示为专业的卡片样式：

| 消息类型 | 颜色 | 图标 | 说明 |
|---------|------|------|------|
| 工具调用 | 🟨 黄色 | 🔧 | 突出显示工具名称和输入参数 |
| 成功结果 | 🟩 绿色 | ✓ | 工具执行成功 |
| 失败结果 | 🟥 红色 | ✗ | 工具执行失败 |
| 思考过程 | 🔵 青色 | 🤔 | Agent 推理步骤 |
| 错误消息 | 🔴 红色 | ✗ | 系统错误 |

### 2. Unicode 框线绘制
使用标准 Unicode 字符绘制精美的卡片边框：

```
┌──────────────────────────────────────┐
│ 标题                                 │
├──────────────────────────────────────┤
│ 内容...                              │
└──────────────────────────────────────┘
```

### 3. ANSI 颜色支持
纯 Node.js 实现，无需外部依赖：
- 文本颜色（红、绿、黄、蓝、青、品红）
- 背景颜色
- 粗体和暗淡样式
- 跨平台兼容

### 4. 智能格式化
- JSON 自动美化和缩进
- 长输出自动截断（>500 字符）
- 多行内容完美支持
- 响应式宽度调整

## 💻 技术实现

### ANSI 转义序列
```typescript
"\x1b[31m"  // 红色文本
"\x1b[32m"  // 绿色文本
"\x1b[33m"  // 黄色文本
"\x1b[43m"  // 黄色背景
"\x1b[0m"   // 重置
"\x1b[1m"   // 粗体
```

### Unicode 框线
```typescript
"┌" "─" "┐"  // 顶部
"│"     "│"  // 左右
"├" "─" "┤"  // 分隔
"└" "─" "┘"  // 底部
```

## 🔧 可配置选项

### 修改卡片颜色
```typescript
createCard({
  title: "Message",
  content: "Content",
  color: "yellow" | "green" | "red" | "blue" | "cyan" | "magenta"
});
```

### 调整卡片宽度
```typescript
createCard({
  title: "Message",
  content: "Content",
  maxWidth: 80  // 默认值，可调整
});
```

### 自定义图标
```typescript
createCard({
  title: "Message",
  content: "Content",
  icon: "🎯"  // 任意 emoji
});
```
